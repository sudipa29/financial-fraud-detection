# Dataset Information

The original transaction dataset used for this project is not included in this repository.

The project was developed using a dataset containing:

* 5,000 financial transactions
* 482 fraudulent transactions
* 4,518 legitimate transactions
* 14 original transaction attributes

Additional analytical features were created during the data preparation and feature engineering stages.

The dataset was processed using Python and MySQL before being used for exploratory data analysis, machine learning and dashboard development.

For privacy, security and repository-size considerations, the raw dataset and database credentials are excluded from the GitHub repository.
